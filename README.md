# MYNDRA

A simple, open way to test the security of AI systems, built on the OWASP Top 10 for LLM Applications 2026.

Website: https://spyrosarg.github.io/myndra-framework-website/
Framework: https://github.com/SpyrosArg/myndra-framework

Every test follows four steps: Define, Attack, Validate, Respond.
